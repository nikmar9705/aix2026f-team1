## ① 주제 확정 / Confirm topic

- 확정 주제 / Topic: 먹지? (이전 이름: Halal Hunter (HxH))
- 이유 / Reason: 안산에 거주하는 무슬림 학생들은 어떤 음식과 장소가 할랄(halal)인지 확인하는 데 어려움을 겪고 있습니다. 공식 인증을 받은 할랄 관련 정보가 거의 없기 때문에, 학생들은 주로 다른 학생들의 입소문이나 개인적인 경험에 의존하는데, 이는 종종 신뢰하기 어렵습니다. 7주차에 범위를 할랄뿐 아니라 음식 프로필(할랄, 비건, 돼지고기 제외)과 알레르기 필터까지 넓혔습니다.

## ③ 범위 결정 / Scope

### Must — 없으면 성립 안 됨 / essential

핵심 시나리오 1개가 끝까지 동작하는 데 필요한 것만 / *Only what the core scenario needs to work end-to-end*

핵심 시나리오 / Core scenario: 사용자가 앱을 열면 → 검색 지도에 ERICA 주변 식당 핀이 음식 종류 로고·배지 개수와 함께 보이고 → 음식 프로필(할랄 / 비건 / 돼지고기 제외)에 맞는 핀이 강조되며 → 핀을 눌러 상세 화면에서 메뉴를 안전 / 먼저 확인 / 피하기로 나누어 보고, 빼야 할 재료, 원산지, 신뢰도와 출처를 확인한다. 검증되지 않은 메뉴는 "미검증"으로 표시된다.
대상 태스크: MVP 마일스톤(11주차) — T1 ~ T9, T13 ~ T16

### Should (없을 경우에는 작성하지 마세요)

실행 패키지 마일스톤(13주차) — T10, T11, T12, T17 ~ T20

- AI 설명("왜?")과 메뉴 사진 스캐너 (T10)
- 사용자 설문 최소 8명 (T11)
- 3분 데모 스크립트와 발표 (T12)
- 개인 메모가 있는 즐겨찾기 (T17)
- 프로필, QR, 친구 (T18)
- 카카오·구글 로그인 (T19)
- 사진 포함 공개 리뷰 (T20)

### 실행 가능성 확인 / Feasibility check

- 특수 장비·유료 API·실제 개인정보가 필요한가? 필요하다면 대안은?
  - 특수 장비는 필요 없다. 테스트는 팀원 본인 휴대폰의 Expo Go로 하며, iPhone 테스트에 Mac이 필요 없다.
  - 지도는 `react-native-maps`를 사용하며 Expo Go 안에서 동작한다. 핀은 자체 데이터에서 가져온다.
  - 데이터는 Supabase(PostgreSQL)에 저장한다. 식당 이름, 전화번호, 좌표는 Kakao Local API로 수집한다. 무료 할당량 조건은 사용 전에 확인한다.
  - AI 호출(T10)은 Python FastAPI 서버를 거치므로 API 키가 앱에 포함되지 않는다. AI 서비스는 유료가 아니며, API 키는 Nik Ammar가 관리한다.
  - 위치는 기기에서만 사용하고 서버에 저장하거나 전송하지 않는다.
  - 카카오·구글 로그인(T19), 프로필 사진, 친구, 리뷰 사진(T20)으로 실제 개인정보를 다루게 된다.
  - 위험: 잘못된 할랄 정보를 주면 사용자에게 피해가 된다. 대안: 직원에게 직접 확인한 정보만 입력하고, 메뉴마다 검증 횟수와 마지막 확인 날짜 또는 "미검증"을 표시한다(T8).
- 15주차에 발표장에서 시연할 수 있는가? 가능하다. Expo Go로 휴대폰에서 실행한다.
