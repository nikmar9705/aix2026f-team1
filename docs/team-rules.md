연락 규칙 / Contact rule — 어디로, 몇 시간 내 응답
-메시지(WhatsApp)로 연락해 주세요. -적절한 시간에만 연락 부탁드립니다.

회의 규칙 / Meeting rule — 요일·시간·불참 처리
-회의를 위해 미리 장소를 정하세요. -늦지 마세요.

기여 규칙 / Contribution rule — 1인당 주 최소 작업량
-모두가 열정적으로 참여해야 해요. 아무리 조금이어도 괜찮아요.

갈등 처리 / Conflict rule — 의견이 갈릴 때
-작은 논쟁은 괜찮아요. 팀 멤버들 사이에서 앙금을 가지지 마세요.

마감 규칙 / Deadline rule
-최소한 하루 안에 모든 것을 완료하세요.

팀 공용 언어 / Working language — 회의 언어 / 기록 언어
-우리의 모국어(말레이어) -영어

AI 사용에 대한 팀 합의 / Team agreement on AI use
-중요하고 개인적인 것을 AI에 붙여넣지 마세요. -가짜 데이터를 만들거나, 값을 지우고 구조만 남기세요.

성찰 / Reflection — 가장 걱정되는 것
-기존 과제를 알아채지 못하고 놓친 것 -수업에서 배운 기술을 충분히 활용하지 못함
