## 데모 시나리오 / Demo scenario — 사용자 한 명의 이야기

할랄을 지키고 땅콩 알레르기가 있는 ERICA 외국인 유학생이 학교 근처에서 먹을 곳을 찾는다. 한국어 메뉴판을 읽기 어렵고, 직원에게 재료를 물어보는 것도 부담스럽다.

1. 앱을 열면 ERICA 중심 지도에 식당 핀이 보인다 (#1)
2. 프로필 탭에서 할랄과 땅콩 알레르기를 켜고, 언어를 영어 ↔ 한국어로 바꿔 본다 (#4, #14, #13)
3. 홈 탭에 거리 설정 안의 맞는 식당이 추천 순위대로 나온다 (#6, #7)
4. 식당을 누르면 메뉴가 안전 / 먼저 확인 / 피하기로 나뉘고, 땅콩이 든 메뉴는 숨겨진다 (#5, #14)
5. 메뉴를 누르면 직원에게 보여 줄 한국어 주문 카드가 뜬다 (#9)
6. "예약하기"를 누르면 전화·복사 버튼과 한국어 문장이 나오고, 마음에 든 식당은 메모와 함께 즐겨찾기에 저장한다 (#16, #17)

## 시연 결과 / 실패 지점 / Result and failure point

MVP 진행: 닫힌 이슈 10 / 13 (#1, #2, #4, #6, #7, #9, #13, #14, #15, #16). 아직 열린 MVP 이슈: #3 시드 데이터, #5 식당 상세, #8 신뢰 배지.

실패 지점:
1. **예약 기능이 크게 부족함 (6단계)** — 지금은 전화·복사 버튼과 연락 기록뿐이고, 앱 안에서 날짜·시간을 정하거나 예약을 취소할 수 없다.
2. **프로필 선택지가 부족함 (2단계)** — 식단은 할랄, 비건, 돼지고기 제외 세 가지와 알레르기뿐이라 다양한 사용자의 음식 취향을 담지 못한다.

## 성찰 / Reflection — 가장 약한 고리

시연에서 드러난 가장 약한 고리는 **예약**이다. 사용자 이야기의 마지막 단계인데, 앱 안에서 끝나지 않고 전화로 넘어간다. 날짜·시간·인원을 정하고 취소하는 흐름(#50)이 있어야 시나리오가 끝까지 이어진다.

시연에서는 보이지 않은 위험은 **데이터 신뢰성**이다. 시드 메뉴는 아직 직원 확인을 거치지 않았고(검증 0회), "미검증" 표시(#8)도 없어서 "안전" 판정이 확인된 사실처럼 보인다. 데이터를 전국으로 넓히면(#47) 이 문제도 같이 커진다.
